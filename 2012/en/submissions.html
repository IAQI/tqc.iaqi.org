Submissions

  • Submission deadline: January 21 (23:59 JST), 2012
  • Notification of acceptance/rejection: March 5, 2012
  • Final version of extended abstracts: May 1 (23:59 JST), 2012
  • Post-proceedings submission: June 30 (23:59 JST), 2012

Notification and submission of extended abstract

All submitted manuscripts will be reviewed by the Program Committee, and notification of acceptance or rejection will be made on March 5, 2012.


Authors of accepted papers for oral presentations or a poster session should prepare a short abstract (at most two pages on A4- or Letter-size paper using at least 11-point fonts) to be included in the book of conference abstracts.


  • The abstract format is the same as the format for poster submission, so please use the same style files. Abstracts should be sent by May 1 (23:59 JST), 2012 in PDF format to tqc2012@gmail.com .
  • The PDF file should be named "TQC012abstract_talk_(presentation number).pdf" for a talk or "TQC012abstract_poster_(presentation number).pdf" for a poster, and the subject of the email should be the same as the file name..

Submission website

All submissions must be made electronically through the online submission system (EasyChair) at the TQC2012 EasyChair page. Please select (exactly) one of the following three categories which your submission most likely fits for choosing the topics:

  • Computer Science
  • Information Theory
  • Physics

Notes on the use of EasyChair

You must have an EasyChair account to submit a paper. To create an account, please go to the EasyChair Signing up page.

Once you register with EasyChair, a confirmation email and a link to create your account will be sent to you. You must finish creating an account within 5 days after your request.

Instructions for speakers and posters

The workshop will consist of invited talks, contributed talks, and a poster session. Contributors can choose a preferred presentation type from Talk only, Poster only, or Talk or Poster. A submission of the Talk or Poster type will be reviewed as an oral presentation and if it is not accepted as an oral presentation, it will then be reviewed as a poster.

The submission deadline is January 21 (23:59 JST), 2012.

Submission for a Contributed Talk

Contributors are asked to submit a paper presenting original, unpublished research results. The paper:

  • Must not exceed 10 pages on Letter-size paper using at least 11-point fonts.
  • Must be in PDF format.
  • Must include the title of the paper, author's names, affiliations, a short abstract summarizing the results, and references.

Please use the template file and the LNCS class file:

  • LaTeX Template file
  • LNCS class file
  • Sample paper in PDF

If you have trouble using these files, please see the LNCS instructions page.

If the authors believe that more details are essential to substantiate the main claims, they may include a clearly marked appendix that will be read at the discretion of the program committee. Simultaneous submission of papers to any other conference with published proceedings or submitting previously published papers is not allowed. See also the TQC'12 submission policy.

Submission for a Poster

Contributors are invited to submit an extended abstract, which:

  • Must not exceed two pages on Letter-size paper using at least 11-point fonts.
  • Must be in PDF format.
  • Must include the title of the paper, author's names, affiliations, a short abstract summarizing the results.
